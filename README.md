# HEMS – Projektpraktikum (TUM, WiSe 26/27)

Statische Ergebnisseite eines studentischen Projekts zu einem Home Energy Management System.
Die Daten sind anonymisierte stündliche Energieflüsse eines Einfamilienhauses (ohne Personen- und Standortangaben).

Die Ergebnisseite ist `index.html`, der Flexibility Manager (Aufgabe 03) liegt unter `flex/`, Markt und Wettbewerber (Aufgabe 04, seit 26.11.2026 eine Seite) unter `market/`; `competitors/` leitet nur noch dorthin weiter. Alle werden aus dem Projektordner per Skript erzeugt, nicht von Hand bearbeitet.
