# HEMS – Projektpraktikum (TUM, WiSe 26/27)

Statische Ergebnisseite eines studentischen Projekts zu einem Home Energy Management System.
Die Daten sind anonymisierte stündliche Energieflüsse eines Einfamilienhauses (ohne Personen- und Standortangaben).

Die Seite ist eine einzelne Datei (`index.html`) und wird aus dem Projektordner per Skript erzeugt, nicht von Hand bearbeitet.
